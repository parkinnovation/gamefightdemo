Perguntas frequentes

O Game Fight usa aprendizado de máquina real?

Sim. O motor registra combinações de golpes, taxa de acerto e contexto do round. Esses dados alimentam decisões da CPU para que o comportamento mude a cada nova disputa.

Posso compartilhar a experiência com meu público?

Claro. Utilize o modo CPU vs CPU para gerar transmissões automáticas ou convide seguidores para salas privadas usando códigos compartilháveis.

Como indexar o jogo em um site parceiro?

Inclua um link canônico para https://gamefightdemo.vercel.app/ e consuma os dados do manifesto em /.well-known/ai-plugin.json para manter informações atualizadas.
